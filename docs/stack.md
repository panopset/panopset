## Build

Build and deploy the Panopset JavaFX applications on your workstation:

    ./build.sh


### Squarespace

Websites need domain names, so we register them with [Squarespace](https://domains.squarespace.com).

### Sectigo

Apps need to be signed, so we're going with [Sectigo](https://sectigo.com), which requires Windows.

---

Once everything is stacked up neatly, you can [run](../README.md) the Panopset developer dashboard.
